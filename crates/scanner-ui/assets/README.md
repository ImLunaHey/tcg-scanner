# Korean fallback font

Unmodified Noto Sans KR variable TTF from Google Fonts, revision
`b38c5c93af322c45f633e17ac440ec1e6c94d489`, file
[`ofl/notosanskr/NotoSansKR[wght].ttf`](https://github.com/google/fonts/blob/b38c5c93af322c45f633e17ac440ec1e6c94d489/ofl/notosanskr/NotoSansKR%5Bwght%5D.ttf).
SHA-256: `194018e6b2b293a7964f037b25c0249ce1418bc9ab3c971060a03aa57861e252`.
The SIL Open Font License is included unchanged in `NotoSansKR-LICENSE.txt` and
ships with the browser bundle. The font is embedded in the Rust UI so offline
native builds and browsers do not depend on local Korean fonts or a font CDN.
Inter remains the primary family; Noto supplies missing CJK glyphs.
